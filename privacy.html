プライバシーポリシー

Live Chat Overlay Makerにおける、 ユーザーデータおよびYouTube API Servicesに関連する データの取り扱いについて説明します。

1. 基本方針

Live Chat Overlay Makerは、ユーザーのプライバシーを尊重し、 本サービスの提供に必要な範囲でのみ情報を取り扱います。

取得した情報は、本ポリシーに記載した目的以外には使用せず、 適用される法令および各サービスの利用規約・ポリシーに従って 適切に管理します。

2. 取り扱う可能性のある情報

Live Chat Overlay Makerでは、提供する機能に応じて、 以下の情報を取り扱う場合があります。

  • ユーザーがアプリ内で指定したチャットデータやCSVファイル
  • チャットメッセージ、投稿時刻、表示名など、オーバーレイ作成に必要な情報
  • YouTube API Servicesを利用する機能において、ユーザーが明示的に許可したAPI Data
  • OAuth 2.0による認証・認可に必要な情報

YouTubeのログインパスワードを Live Chat Overlay Makerが取得または保存することはありません。

3. 情報の利用目的

取り扱う情報は、主に以下の目的で使用します。

  • チャットデータを読み込むため
  • コメントの投稿時刻を動画の時間軸に同期するため
  • 動画編集で利用できるチャットオーバーレイ素材を作成するため
  • ユーザーが選択した機能を提供するため
  • 不具合対応およびサービス品質の維持に必要な範囲で利用するため

4. YouTube API Servicesについて

Live Chat Overlay Makerは、 YouTubeに関連する機能を提供する場合、 YouTube API Servicesを利用することがあります。

YouTube API Servicesを利用する機能については、 YouTube API Services Terms of Service、 YouTube Developer Policiesその他の関連ポリシーに従って提供します。

YouTube API Servicesを通じて取得するデータは、 ユーザーに説明した目的およびユーザーが許可した範囲でのみ利用します。

YouTube API Servicesを利用する機能は現在、 適切な承認およびポリシーへの準拠を確認しながら 提供準備を進めています。

6. YouTube利用規約

YouTube API Servicesを利用する機能を使用する場合、 ユーザーはYouTubeの利用規約にも従う必要があります。

7. データの保存と削除

Live Chat Overlay Makerは、 YouTube API Servicesから取得したデータを、 機能提供に必要な範囲および適用されるYouTubeのポリシーで 認められる期間に限って取り扱います。

保存が必要なAPI Dataについては、 YouTube Developer Policiesで定められた更新・削除要件に従い、 必要に応じて更新または削除します。

ユーザーから保存データの削除依頼を受けた場合は、 適用されるポリシーに従い、可能な限り速やかに対応します。

Live Chat Overlay Maker側に保存されたデータを削除しても、 YouTube上に保存されている元のデータが削除されるわけではありません。 YouTube上のデータを削除する場合は、 YouTubeが提供するサービスまたは適切な機能をご利用ください。

8. Googleアカウントとの連携解除

YouTube API Servicesへのアクセスを許可した場合、 ユーザーはGoogleアカウントのセキュリティ設定から アクセス権を確認・解除できます。

Google アカウントのアクセス権管理

アクセス権が解除された場合、 関連するAPI Dataについては、 YouTube Developer Policiesに従って削除等の対応を行います。

9. 第三者への提供

法令に基づく場合を除き、 ユーザー情報を本ポリシーに記載した目的と無関係な第三者へ 販売することはありません。

外部サービスを利用する必要がある場合には、 そのサービスの提供に必要な範囲でのみ情報が処理されるよう努めます。

10. セキュリティ

Live Chat Overlay Makerは、 取り扱う情報への不正アクセス、紛失、漏えい、改ざん等を防止するため、 合理的かつ適切な安全管理措置を講じるよう努めます。

削除依頼を受けた場合は、 適用される法令およびYouTube Developer Policiesに従って対応します。
