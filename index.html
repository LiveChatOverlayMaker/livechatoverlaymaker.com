Live Chat Overlay Maker

ライブ配信のチャットを、
動画編集で使えるオーバーレイ素材へ。

Live Chat Overlay Makerは、配信後のチャットデータを読み込み、 コメントの投稿時刻を動画のタイムラインに合わせて表示し、 動画編集ソフトで使えるオーバーレイ映像として書き出す Windows向けデスクトップアプリです。

HOW IT WORKS

使い方はシンプルな3ステップ

1

チャットデータを用意

対応するチャットデータや、 エクスポートしたCSVファイルを読み込みます。

2

表示スタイルと範囲を設定

プレビューを確認しながら、 表示する時間範囲やデザインを調整します。

3

オーバーレイ映像を書き出す

設定した内容で映像を書き出し、 動画編集ソフトへ追加して仕上げます。

SUPPORTED DATA SOURCES

対応状況

Twitch

配信後のチャットデータを利用した 動画編集向けオーバーレイ作成に対応しています。

CSVファイル

対応形式のCSVチャットデータを読み込み、 オーバーレイ映像の作成に利用できます。

YouTube 準備中

YouTube API Servicesを利用する機能については、 適切な承認およびポリシーへの準拠を確認しながら 提供準備を進めています。

ABOUT

配信の思い出を、編集できる素材へ。

Live Chat Overlay Makerは、 ライブ配信終了後のチャットを動画の時間軸に合わせて再現し、 動画編集で利用できる素材として書き出すことを目的とした Windowsデスクトップアプリです。

配信者自身の動画編集だけでなく、 権限を持つ編集者が配信アーカイブから動画を制作する場面でも、 チャットを映像表現の一部として活用できることを目指しています。

あの時のコメントを、映像に残そう。

Live Chat Overlay Makerは現在、 正式公開に向けて開発と準備を進めています。
